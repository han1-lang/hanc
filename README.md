# Han

[English](README.en.md)

Han（Human-Agent Notation）是一门系统级编程语言。源文件使用 `.han`。代码按顺序阅读，编译器把它转到 C，再生成本机程序。

本仓库名为 Hanc。它只发布 Han 项目的版本文件，不存放编译器源码，也不存放设计文档。

## 下载

打开本仓库页面上的 Releases，选择一个版本。每个 Release 对应一个 Git tag，两者使用同一个版本字符串。

下载前先读该版本的发布说明，再用同一次 Release 里的 `SHA256SUMS` 核对附件。版本号以 Release 标题为准。

| 附件 | 内容 |
| --- | --- |
| 发布说明 | 这一版包含哪些文件、能在什么环境下使用 |
| `SHA256SUMS` | 本 Release 全部附件的 SHA-256 |
| 版本发布文件 | 该版本实际提供的编译器与工具包；文件名带版本与目标平台 |

已发布的 tag 不再改写。某一版停止提供下载时，在该 Release 的说明里写明由哪一版取代。

## 工具

| 命令 | 作用 |
| --- | --- |
| `han` | 日常入口。单文件直接编译运行；发现工程配置时交给 `hake` |
| `h2c` | 核心编译器，把 `.han` 转到 C。`.v` 仍按 V 语言处理 |
| `hake` | 工程构建：依赖、多语言编译与链接 |
| `vp` | 过渡期工具，用于兼容 V。Han 源码的日常入口是 `han` |

`h2cpp`、`h2js`、`h2llvm` 尚未作为发布文件提供。

## 语言里已经在用的方向

- 声明仍写普通函数；会停下的调用由编译器识别，并发启动使用 `launch` / `async`
- 构建与依赖由 Hake 工程描述，不靠散落的脚本拼命令
- 与 C 一起编译、链接；V 源文件可以继续由同一套工具链处理

具体语法与接口以该版本发布说明所指向的手册为准。
